**PLEASE NOTE FOLLOWINGS BEFORE USING THE TEMPLATE:**
1. To ensure proper formatting, please download '**word-template.docx**' and place it in the **PARENT DIRECTORY** of your working folder (i.e., ../word-template.docx). This is required for the correct rendering of the output document.

2. The pre-defined inclusion/exclusion criteria for healthy volunteer trials in this template are based on the guidelines of my institution, so there may be discrepancies with your institution’s requirements. Please review the output document **thoroughly** and revise it as needed to align with your institution’s guidelines.

3. Since it is **NOT FULLY AUTOMATED** PROTOCOL GENERATION template, there are still sections you need to write in yourself (It is still very few for manual writing than writing protocol in full manually tho :)). After knitting, you can search the word **"MANUALLY"** in Word by ctrl+F to find sections you need to insert manually.

4. There are sections you can use pre-defined sample sentences within Rmd file. If you search "**OPTIONAL:**" in .Rmd template by ctrl+F, you can find certain parts with sample sentences you can use if needed. Otherwise, preset as Not Applicable.
