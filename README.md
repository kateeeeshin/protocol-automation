**PLEASE NOTE FOLLOWINGS BEFORE USING THE TEMPLATE:**
1. To ensure proper formatting, please download '**word-template.docx**' and place it in the **PARENT DIRECTORY** of your working folder (i.e., ../word-template.docx). This is required for the correct rendering of the output document.

2. The pre-defined inclusion/exclusion criteria for healthy volunteer trials in this template are based on the guidelines of my institution, so there may be discrepancies with your institution’s requirements. Please review the output document **thoroughly** and revise it as needed to align with your institution’s guidelines.

3. Since this is not a fully automated protocol generation template, there are still some sections that require manual writing. However, the manual input needed is significantly reduced compared to writing a full protocol from scratch. After knitting, you can use **Ctrl+F** to search for the word **"MANUALLY"** in the generated Word document to locate the sections that require manual input.

4. Additionally, there are sections in the .Rmd template where you can use pre-defined sample sentences. To find them, search for **"OPTIONAL:"** in the .Rmd file using **Ctrl+F**. These sample sentences can be used as needed, or you can leave them as Not Applicable if they do not apply.
